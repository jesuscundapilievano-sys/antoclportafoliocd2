01

¿Qué es HTML5?

DEFINICIÓN

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Es el esqueleto de cualquier sitio: define la estructura y el significado del contenido. HTML5 es su versión más moderna, lanzada en 2014 y mantenida por el W3C.

No es un lenguaje de programación: no tiene lógica ni condiciones. Es un lenguaje de marcado que usa etiquetas (tags) para describir el contenido.

¿QUÉ HACE HTML?

  • Define títulos, párrafos e imágenes
  • Estructura la información en secciones
  • Crea formularios y botones
  • Enlaza páginas entre sí
  • Incrusta video y audio

¿QUÉ NO HACE HTML?

  • No da estilo (eso es CSS)
  • No añade interactividad (eso es JS)
  • No guarda datos en un servidor
  • No tiene bucles ni variables
💡 TIP

La web se construye con 3 capas: HTML (estructura) + CSS (estilo) + JavaScript (comportamiento). Esta guía cubre la primera capa.

02

Configuración del entorno

HERRAMIENTAS NECESARIAS

Para escribir HTML solo necesitas dos cosas:

  1. Editor de código — Recomendado: VS Code (gratuito)
  2. Navegador web — Chrome, Firefox, Edge o Safari
INSTALAR VS CODEDescarga VS Code desde code.visualstudio.com e instálalo. Es el editor más popular entre desarrolladores web.
CREAR CARPETA DE PROYECTOCrea una carpeta llamada mi-sitio-web en tu escritorio. Ahí irán todos tus archivos.
CREAR EL PRIMER ARCHIVODentro de la carpeta, crea un archivo llamado index.html. El nombre index es especial: es la página principal.
INSTALAR LIVE SERVEREn VS Code busca la extensión Live Server. Te permite ver tu página en el navegador y que se actualice automáticamente al guardar.
03

Estructura base de un documento HTML

EL ESQUELETO MÍNIMO

Todo archivo HTML debe comenzar con esta estructura. VS Code la genera al escribir ! y presionar Tab:

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mi primera página</title> </head> <body> <!-- Aquí va el contenido visible --> <h1>¡Hola, mundo!</h1> </body> </html>

PARTES DEL DOCUMENTO

EtiquetaFunción
<!DOCTYPE html>Declara HTML5
<html>Raíz de la página
<head>Metadatos (no visibles)
<body>Contenido visible

ANATOMÍA DE UNA ETIQUETA

<!-- Etiqueta con apertura y cierre --> <p>Texto del párrafo</p> <!-- Etiqueta auto-cerrada --> <img src="foto.jpg" alt="mi foto">
📌 REGLA IMPORTANTE

Las etiquetas que abren deben cerrarse: <p> → </p>. El slash / indica cierre. Algunas se cierran solas: <br>, <img>, <meta>.

04

Etiquetas esenciales

ENCABEZADOS (HEADINGS)

HTML tiene 6 niveles. <h1> es el más importante (solo uno por página) y <h6> el de menor jerarquía.

<h1>Título principal de la página</h1> <h2>Sección importante</h2> <h3>Sub-sección</h3> <h4>Sub-sub-sección</h4>

PÁRRAFOS Y TEXTO

<p>Este es un párrafo de texto normal.</p> <p> Texto con <strong>negritas</strong>, <em>cursivas</em> y <mark>marcado</mark>. </p> <br> <!-- Salto de línea --> <hr> <!-- Línea horizontal -->

ENLACES E IMÁGENES

<!-- Enlace externo --> <a href="https://ejemplo.com" target="_blank"> Visitar sitio </a> <!-- Ancla: enlace a sección de la misma página --> <a href="#contacto">Ir a contacto</a> <!-- Imagen --> <img src="foto.jpg" alt="Descripción de la imagen" width="300">

ATRIBUTOS CLAVE

AtributoUso
idIdentificador único
classGrupo (para CSS/JS)
hrefURL de un enlace
srcRuta de imagen/video
altTexto alternativo
targetDónde abrir el enlace

CONTENEDORES GENÉRICOS

<!-- Bloque (ocupa toda la línea) --> <div class="tarjeta"> Contenido aquí </div> <!-- En línea (dentro del texto) --> <span class="destacado">palabra</span>
05

Semántica HTML5

¿QUÉ ES LA SEMÁNTICA?

HTML5 introdujo etiquetas que describen el significado del contenido, no solo su apariencia. Esto mejora la accesibilidad y el SEO. En lugar de usar solo <div> para todo, HTML5 nos da etiquetas específicas:

<body> <header> <!-- Logo, nombre del sitio, navegación principal --> <nav> <a href="#inicio">Inicio</a> <a href="#servicios">Servicios</a> </nav> </header> <main> <section id="inicio"> <article> <h2>Artículo de blog</h2> <p>Contenido del artículo...</p> </article> </section> <aside><!-- Sidebar, widgets --></aside> </main> <footer> <p>&copy; 2025 Mi Sitio</p> </footer> </body>

MAPA DE ETIQUETAS SEMÁNTICAS

EtiquetaSignificadoCuándo usarla
<header>CabeceraLogo, menú, nombre del sitio
<nav>NavegaciónMenú de enlaces
<main>Contenido principalUna sola vez por página
<section>Sección temáticaGrupo de contenido relacionado
<article>ArtículoPost, noticia, tarjeta
<aside>Contenido secundarioSidebar, widget, anuncio
<footer>Pie de páginaCréditos, copyright, enlaces

Multimedia

VIDEO

<video src="video.mp4" controls width="100%" poster="thumbnail.jpg"> Tu navegador no soporta video. </video>
  • controls → muestra controles
  • autoplay → reproduce solo
  • loop → repite en bucle
  • muted → sin sonido

09

Buenas prácticas

REGLAS DE ORO

  • Siempre usa el atributo alt en imágenesAccesibilidad
  • Un solo <h1> por páginaSEO
  • Usa etiquetas semánticas, no solo <div>Semántica
  • Indenta correctamente el códigoLegibilidad
  • Valida tu HTML en validator.w3.orgCalidad

✅ HACER

  • Escribir HTML en minúsculas
  • Cerrar todas las etiquetas
  • Usar nombres descriptivos para ids/clases
  • Comentar secciones importantes
  • Mantener el código organizado e indentado

❌ EVITAR

  • Usar estilos inline en exceso
  • Usar tablas para maquetar
  • Saltarse niveles de encabezado
  • Etiquetas obsoletas como <font>
  • Imágenes sin atributo alt
