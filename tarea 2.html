🌐 Desarrollo Web
💡

El desarrollo web utiliza tres pilares fundamentales: HTML para la estructura, CSS para el estilo visual y JavaScript para la interactividad. Sobre ellos se construye todo lo que ves en internet.

HTML 5
Lenguaje de Marcado

HyperText Markup Language es el esqueleto de toda página web. Define la estructura y el contenido mediante etiquetas semánticas. No es un lenguaje de programación, sino de marcado: describe qué es cada elemento (título, párrafo, imagen, botón).

Páginas web Correos HTML Apps web PWA
index.html
<!-- Estructura básica HTML5 --> <!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"/> <title>Mi Página</title> </head> <body> <header> <h1>Cultura Digital 2</h1> <nav> <a href="#">Inicio</a> </nav> </header> <main> <p>¡Hola mundo!</p> </main> </body> </html>
CSS 3
Hojas de Estilo

Cascading Style Sheets controla la apariencia visual de los elementos HTML: colores, tipografías, espacios, animaciones y el diseño responsivo. Con CSS moderno se pueden crear experiencias visuales sofisticadas sin necesidad de imágenes.

Diseño responsivo Animaciones Temas visuales Grid/Flexbox
estilos.css
/* Variables y tema global */ :root { --color-principal: #1565c0; --fuente-base: 'Nunito', sans-serif; } body { font-family: var(--fuente-base); background: #f0f4f8; } .tarjeta { background: white; border-radius: 16px; padding: 24px; box-shadow: 0 4px 20px rgba(0,0,0,.1); transition: transform .3s ease; } .tarjeta:hover { transform: translateY(-6px); }
JavaScript
Lenguaje de Programación

El único lenguaje de programación que los navegadores ejecutan de forma nativa. Aporta interactividad, lógica y dinamismo a las páginas web. Con Node.js también se usa en el servidor, y es la base de frameworks modernos como React, Vue y Angular.

Interactividad React / Vue Node.js APIs IA en web
app.js
// Función de saludo con IA const saludar = (nombre) => { return `¡Hola, ${nombre}!`; }; // Arreglo de lenguajes const lenguajes = [ "HTML", "CSS", "JavaScript" ]; // Recorrer e imprimir lenguajes.forEach((lang) => { console.log(`Lenguaje: ${lang}`); }); // Llamar la función saludar("Antonio"); // → ¡Hola, Antonio!
PHP
Backend Web

PHP es un lenguaje del lado del servidor que impulsa el 70% de los sitios web del mundo, incluyendo WordPress, Facebook (en sus inicios) y Wikipedia. Se encarga de procesar formularios, conectar bases de datos y generar HTML dinámico.

WordPress Bases de datos Formularios Servidores

🖥 Desarrollo de Escritorio
🤖

Los lenguajes de escritorio son fundamentales para la Inteligencia Artificial. Python lidera el mundo del Machine Learning, mientras que Java y C++ siguen siendo clave en sistemas de alto rendimiento.

Python
IA · Ciencia de Datos

El lenguaje más popular del mundo en 2024. Su sintaxis es simple y legible, lo que lo hace ideal para principiantes y expertos. Es el lenguaje principal de la Inteligencia Artificial, Machine Learning y análisis de datos con librerías como TensorFlow, PyTorch y scikit-learn.

Machine Learning Data Science Automatización TensorFlow ChatGPT/Claude
ia_basica.py
# Clasificador simple con Python import numpy as np # Datos de entrenamiento datos = np.array([1,2,3,4,5]) etiquetas = ["bajo","bajo","medio", "alto", "alto"] # Función de clasificación def clasificar(valor): if valor <= 2: return "bajo" elif valor == 3: return "medio" else: return "alto" print(clasificar(4)) # → alto
Java
Multiplataforma

"Write once, run anywhere": Java se ejecuta en cualquier sistema operativo gracias a la Máquina Virtual de Java (JVM). Es la base de millones de aplicaciones empresariales, Android y sistemas bancarios en todo el mundo.

Android Empresarial Banca Spring Boot

C++
Alto Rendimiento

Uno de los lenguajes más poderosos y rápidos que existen. Es la base de videojuegos AAA, sistemas operativos, motores gráficos y software médico. Los núcleos de TensorFlow (IA) y Chrome están escritos en C++.

Videojuegos Unreal Engine Robótica Sistemas

🎨 Diseño y Maquetación
🎨

El diseño digital va más allá de lo visual: combina comunicación, experiencia de usuario (UX) y tecnología. Los lenguajes y herramientas de diseño permiten construir interfaces que las personas disfrutan usar.

SASS / SCSS
Preprocesador CSS

SASS es CSS con superpoderes. Añade variables, funciones, anidación y mixins que hacen el código de estilos más organizado, reutilizable y mantenible. Se compila a CSS estándar y es usado en proyectos profesionales de diseño web.

Variables Mixins Anidación Bootstrap
estilos.scss
// Variables reutilizables $azul: #1565c0; $verde: #00e5b0; $radio: 16px; // Mixin para botones @mixin boton($bg, $color) { background: $bg; color: $color; border-radius: 50px; padding: 10px 24px; } // Anidación de selectores .tarjeta { border-radius: $radio; &:hover { border-color: $azul; } .btn { @include boton($azul, white); } }
SVG
Gráficos Vectoriales

Scalable Vector Graphics es un formato de imagen basado en XML que describe gráficos con matemáticas puras, por eso nunca pierden calidad al escalar. Ideal para íconos, logotipos, ilustraciones y animaciones interactivas en la web.

Íconos Logotipos Ilustración web Animaciones

Markdown
Maquetación de Texto

Un lenguaje de marcado ligero que permite dar formato a texto plano de forma simple e intuitiva. Es el estándar para documentación técnica, README de proyectos, wikis y plataformas como GitHub, Notion y Obsidian. Los modelos de IA como Claude lo usan por defecto.
