01 — Introducción

¿Qué es Python?

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general. Fue creado por Guido van Rossum y publicado en 1991.

⚡
Simple y legible
Su sintaxis es clara y se asemeja al pseudocódigo, permitiendo enfocarse en la lógica y no en la sintaxis.
🌍
Multiplataforma
Funciona en Windows, macOS y Linux sin necesidad de cambiar el código.
📦
Gran ecosistema
Miles de librerías disponibles: ciencia de datos, web, IA, automatización y más.
🔄
Multiparadigma
Soporta programación imperativa, funcional y orientada a objetos.
02 — Fundamentos

Tipos de datos

Python tiene tipado dinámico: el tipo se asigna automáticamente al valor, no a la variable.

TipoEjemploDescripción
int42, -7, 0Números enteros sin límite de tamaño
float3.14, -0.5Números decimales (punto flotante)
complex2+3jNúmeros complejos
str"Hola", 'mundo'Cadenas de texto, inmutables
boolTrue, FalseValores booleanos (subclase de int)
NoneTypeNoneAusencia de valor
python 
# Verificar el tipo de una variable
x = 42
y = 3.14
z = "Python"
flag = True

print(type(y))    # <class 'float'>

# Conversión de tipos
numero = int("100")   # "100" → 100
texto  = str(3.14)    # 3.14  → "3.14"
03 — Fundamentos

Variables y operadores

Las variables se crean con la asignación directa. Los nombres son case-sensitive y no pueden empezar con un número.

python 
# Asignación múltiple
a, b, c = 1, 2, 3
x = y = 0

# Operadores aritméticos
print(10 + 3)   # 13  suma
print(10 - 3)   # 7   resta
print(10 * 3)   # 30  multiplicación
print(10 / 3)   # 3.333... división real
print(10 // 3)  # 3   división entera
print(10 % 3)   # 1   módulo (resto)
print(2  ** 8)  # 256 exponenciación

# Operadores de comparación
5 == 5   # True
5 != 3   # True
5 >= 5   # True

# Operadores lógicos
True and False  # False
True or  False  # True
not True        # False
04 — Control de flujo

Estructuras de control

Python usa la indentación (4 espacios) para delimitar bloques, en lugar de llaves o palabras clave como END.

python 
# Condicional if / elif / else
edad = 20
if edad < 13:
    print("Niño")
elif edad < 18:
    print("Adolescente")
else:
    print("Adulto")    # ← se ejecuta esta

# Bucle for (iteración)
for i in range(5):           # 0, 1, 2, 3, 4
    print(i, end=" ")

# Bucle while
contador = 0
while contador < 3:
    print(contador)
    contador += 1

# break, continue, pass
for n in range(10):
    if n == 3: continue   # salta el 3
    if n == 7: break     # detiene el bucle
    print(n)
05 — Funciones

Funciones

Las funciones son bloques de código reutilizables. En Python son objetos de primera clase: se pueden asignar a variables, pasar como argumentos y retornar.

python 
# Definición básica
def saludar(nombre, saludo="Hola"):
    return f"{saludo}, {nombre}!"

print(saludar("Ana"))            # Hola, Ana!
print(saludar("Ana", "Buenos días")) # Buenos días, Ana!

# *args y **kwargs
def suma(*numeros):
    return sum(numeros)

print(suma(1, 2, 3, 4))   # 10

# Funciones lambda (anónimas)
cuadrado = lambda x: x ** 2
print(cuadrado(7))   # 49

# Función como argumento
nums = [3, 1, 4, 1, 5]
print(sorted(nums, key=lambda x: -x))   # [5, 4, 3, 1, 1]

Tip: Las funciones pueden devolver múltiples valores: return a, b retorna una tupla. Se desempaqueta con x, y = mi_funcion().

06 — Estructuras de datos

Listas, Tuplas, Diccionarios y Conjuntos

Estas cuatro estructuras son el núcleo del trabajo con datos en Python. Cada una tiene características únicas.

python 
## LISTA — mutable, ordenada, permite duplicados
frutas = ["manzana", "pera", "uva"]
frutas.append("mango")          # añadir al final
frutas.insert(1, "kiwi")         # insertar en posición
frutas.remove("pera")            # eliminar por valor
print(frutas[0])                 # "manzana" (índice)
print(frutas[1:3])               # slicing

## TUPLA — inmutable, ordenada
coordenadas = (40.71, -74.00)
lat, lon = coordenadas             # desempaquetado

## DICCIONARIO — pares clave:valor, mutable
persona = {"nombre": "Luis", "edad": 30}
persona["ciudad"] = "CDMX"       # agregar clave
print(persona.get("edad", 0))    # 30
for k, v in persona.items():
    print(f"{k}: {v}")

## CONJUNTO (set) — sin duplicados, sin orden
colores = {"rojo", "azul", "rojo"}
print(colores)   # {'rojo', 'azul'}

## COMPRENSIÓN DE LISTA (list comprehension)
cuadrados = [x**2 for x in range(10) if x % 2 == 0]
# [0, 4, 16, 36, 64]
07 — POO

Programación Orientada a Objetos

Python es un lenguaje orientado a objetos. Todo en Python es un objeto, incluyendo los tipos primitivos.

python 
class Animal:
    """Clase base."""
    especie = "Desconocida"   # atributo de clase

    def __init__(self, nombre, edad):
        self.nombre = nombre   # atributo de instancia
        self.edad   = edad

    def describir(self):
        return f"{self.nombre}, {self.edad} años"

    def hablar(self):   # método a sobreescribir
        raise NotImplementedError


class Perro(Animal):   # Herencia
    especie = "Canis lupus familiaris"

    def hablar(self):
        return "¡Woof!"


rex = Perro("Rex", 4)
print(rex.describir())    # Rex, 4 años
print(rex.hablar())       # ¡Woof!
print(isinstance(rex, Animal))  # True
📦
Encapsulamiento
Prefijo _ indica protegido, __ indica privado (name mangling).
🔗
Herencia
Una clase puede heredar de una o varias clases base y sobreescribir métodos.
🎭
Polimorfismo
Distintos objetos responden al mismo mensaje de forma diferente.

09 — Errores

Manejo de excepciones

Python usa un bloque try / except / else / finally para manejar errores sin que el programa se interrumpa abruptamente.

python 
try:
    resultado = 10 / 0
except ZeroDivisionError as e:
    print(f"Error: {e}")     # Error: division by zero
except (TypeError, ValueError):
    print("Tipo o valor incorrecto")
else:
    print("Sin errores")     # se ejecuta si no hubo excepción
finally:
    print("Siempre se ejecuta")

# Lanzar excepciones propias
class EdadInvalidaError(Exception): pass

def verificar_edad(edad):
    if edad < 0:
        raise EdadInvalidaError("La edad no puede ser negativa")
10 — Archivos

Lectura y escritura de archivos

La gestión de archivos usa el gestor de contexto with, que garantiza el cierre automático del archivo.

python 
# Escribir
with open("datos.txt", "w", encoding="utf-8") as f:
    f.write("Hola Python\n")
    f.writelines(["Línea 2\n", "Línea 3\n"])

# Leer
with open("datos.txt", "r", encoding="utf-8") as f:
    contenido = f.read()          # todo el archivo
    # líneas = f.readlines()      # lista de líneas

# JSON
import json
datos = {"nombre": "María", "notas": [9, 8, 10]}

with open("datos.json", "w") as f:
    json.dump(datos, f, indent=2)

with open("datos.json") as f:
    cargado = json.load(f)
11 — Avanzado

Conceptos avanzados esenciales

Características que elevan el nivel de tu código Python.

python 
## DECORADORES — modifican funciones sin cambiarlas
def cronometrar(func):
    import time
    def wrapper(*args, **kwargs):
        inicio = time.time()
        resultado = func(*args, **kwargs)
        print(f"{func.__name__} tardó {time.time()-inicio:.4f}s")
        return resultado
    return wrapper

@cronometrar
def proceso_largo():
    return sum(range(10_000_000))


## GENERADORES — producen valores uno a uno (memoria eficiente)
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

print(list(fibonacci(8)))   # [0,1,1,2,3,5,8,13]


## CONTEXT MANAGERS con clase
class ConexionDB:
    def __enter__(self):
        print("Conectando...")
        return self
    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Cerrando conexión")

with ConexionDB() as db:
    print("Usando DB...")
